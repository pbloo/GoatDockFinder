# Site do GoatDockFinder

Página estática (HTML, CSS e JavaScript puros, sem build) com uma demonstração interativa da dock e do catálogo de widgets. Dados ilustrativos; a página não acessa nada do computador.

- Ver localmente: `npx serve .` ou `python -m http.server 8000` nesta pasta, ou abrir `index.html` no navegador.
- Links do GitHub: preencha `REPO_URL` no começo de `script.js`. Vazio, eles ficam escondidos.
- Cores e tema: variáveis no início de `style.css` (`:root`).
- Publicar na Vercel: veja `docs/PUBLICAR.md` (Root Directory = `vercel`).
