# Código de Conduta

Como contribuidores e mantenedores deste projeto, nos comprometemos a respeitar todas as pessoas que participam por issues, pull requests ou qualquer outro canal.

## Esperamos

- Respeito e clareza ao discordar: critique a ideia, não a pessoa.
- Paciência com quem está começando. Todo mundo já foi iniciante.
- Foco no que é melhor para o projeto e para quem o usa.

## Não toleramos

- Assédio, insultos, discriminação ou linguagem ofensiva.
- Exposição de dados pessoais de outras pessoas sem consentimento.
- Spam e autopromoção fora de contexto.

## Aplicação

Mantenedores podem editar, ocultar ou remover comentários, issues e pull requests que violem este código, e podem bloquear quem o descumprir de forma repetida. Para relatar um problema, abra uma issue marcada como privada pelas opções do repositório ou entre em contato com o mantenedor pelo perfil do GitHub.
